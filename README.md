# Daily Brief

Personal mobile-first dashboard with balanced news (politics + medicine/tech), GenAI tips for advanced Claude/ChatGPT users, and weather for Minneapolis & Puerto Escondido.

**Live:** https://jcpeters08.github.io/news-app/

## How it works

- A scheduled GitHub Action runs at exact 6:00am and 1:00pm America/Chicago, year-round (DST-safe — gating happens in the script, not the cron expression).
- The Action fetches news from NewsAPI, GenAI items from a curated set of RSS feeds, and weather from Open-Meteo.
- Output is written to `public/data.json` and deployed to GitHub Pages.
- The static frontend (`public/`) reads `data.json` on load.

## Setup (one time)

### 1. NewsAPI key

1. Go to https://newsapi.org/register and create a free account.
2. Verify your email and grab your API key from the dashboard.
3. In this repo on GitHub: **Settings → Secrets and variables → Actions → New repository secret**.
4. Name: `NEWSAPI_KEY` · Value: your key. Save.

### 1b. Anthropic API key (optional but recommended)

If set, Claude reads the candidate stories each run and (a) picks the most
personally relevant 5 per category, (b) writes a 1–2 sentence "why this
matters" gloss per story, and (c) generates a 2–3 sentence daily brief at
the top of the dashboard. Without it, the build falls back to recency-based
picks with no glosses.

1. Go to https://console.anthropic.com → add billing (~$5 covers many months).
2. Settings → API Keys → Create Key.
3. Add to repo: secret name `ANTHROPIC_API_KEY`.
4. Optional: repository **variable** `CLAUDE_MODEL` (default `claude-opus-4-5`).
   Set to `claude-haiku-4-5` for ~15× lower cost.

Cost notes (twice-daily cron):
- **Opus** (default): ~$10–15/month
- **Haiku**: ~$0.30–1.20/month

Curation preferences live in [scripts/prefs.js](scripts/prefs.js) — edit that
file (no code changes elsewhere) to retune what Claude prioritizes.

### 2. Enable GitHub Pages

- **Settings → Pages → Build and deployment → Source: GitHub Actions**.
- The first deploy happens automatically on the next Action run (cron or manual).

### 3. (Optional) Local development

```bash
npm install
cp .env.example .env   # add your NEWSAPI_KEY
FORCE_RUN=1 NEWSAPI_KEY=$(grep NEWSAPI_KEY .env | cut -d= -f2) npm run build:data
npm run preview        # http://localhost:5173
```

## Schedule

Cron runs every UTC hour that *might* be 6am or 1pm in Chicago across DST: `11, 12, 18, 19 UTC`. The build script checks `Intl.DateTimeFormat` with `America/Chicago` and only proceeds when the local hour is exactly `6` or `13`. Otherwise it exits without writing.

To override (e.g. you want a manual refresh): **Actions → Build & Deploy → Run workflow** with `force=true`.

## Data sources

- **Politics:** NewsAPI top-headlines from a curated allowlist of left/center/right outlets, with AllSides-style lean badges.
- **Medicine & Tech:** NewsAPI top-headlines from Reuters/AP/BBC/Verge/Ars/Wired/TechCrunch/MNT/etc.
- **GenAI:** RSS from Anthropic, OpenAI, Simon Willison, Latent Space, and Hacker News (filtered for Claude/ChatGPT/LLM keywords).
- **Weather:** Open-Meteo (no API key).

## Bias ratings

Source-bias mapping is in [scripts/sources.js](scripts/sources.js). Adapted from AllSides and Ad Fontes consensus. PRs welcome to update.

## Tests

